Cài đặt vào dự án Apps Script

Sao chép 4 file vào project rồi chèn vào template

  1. 1
    Thêm các file TXUI_Head.html, TXUI_Styles.html, TXUI_Scripts.html, TXUI_Server.gs vào project.
  2. 2
    Trong doGet() dùng TXUI.render('Index', {...}, 'Tiêu đề').
  3. 3
    Chèn Head trong thẻ <head> và Scripts cuối <body> (xem code bên cạnh).
  4. 4
    Dùng class (btn btn-primary, card, form-control...) và API TXUI.toast(), TXUI.call()...
<!DOCTYPE html>
<html lang="vi">
<head>
  <?!= include('TXUI_Head'); ?>
</head>
<body>
  <button class="btn btn-primary" onclick="save()">
    <i class="fa-solid fa-floppy-disk"></i> Lưu
  </button>

  <?!= include('TXUI_Scripts'); ?>
  <script>
    function save() {
      TXUI.call('saveData', [{ a: 1 }], { success: 'Đã lưu!' });
    }
  </script>
</body>
</html>

DataTable

Tìm kiếm không dấu, sắp xếp, phân trang, chọn dòng, xuất CSV – dữ liệu tải từ server qua TXUI.run()

var dt = new TXUI.DataTable('#empTable', {
  columns: [
    { key: 'id', label: 'Mã NV', width: '100px' },
    { key: 'name', label: 'Họ tên', render: (v, r) => `<b>${TXUI.escape(v)}</b>` },
    { key: 'dept', label: 'Bộ phận' },
    { key: 'salary', label: 'Lương', align: 'right', format: 'currency' },
    { key: 'joined', label: 'Ngày vào', format: 'date' }
  ],
  selectable: true, exportable: true, pageSize: 10,
  onRowClick: row => TXUI.toast(row.name)
});
dt.setLoading(true);
TXUI.run('demo_getEmployees').then(rows => dt.setData(rows));
