Cài đặt vào dự án Apps Script

Sao chép 4 file vào project rồi chèn vào template

  1. 1
    Thêm các file TXTV_Head.html, TXTV_Styles.html, TXTV_Scripts.html, TXTV_Server.gs vào project.
  2. 2
    Trong doGet() dùng TXTV.render('Index', {...}, 'Tiêu đề').
  3. 3
    Chèn Head trong thẻ <head> và Scripts cuối <body> (xem code bên cạnh).
  4. 4
    Dùng class (btn btn-primary, card, form-control...) và API TXTV.toast(), TXTV.call()...
<!DOCTYPE html>
<html lang="vi">
<head>
  <?!= include('TXTV_Head'); ?>
</head>
<body>
  <button class="btn btn-primary" onclick="save()">
    <i class="fa-solid fa-floppy-disk"></i> Lưu
  </button>

  <?!= include('TXTV_Scripts'); ?>
  <script>
    function save() {
      TXTV.call('saveData', [{ a: 1 }], { success: 'Đã lưu!' });
    }
  </script>
</body>
</html>

var dt = new TXTV.DataTable('#empTable', {
  columns: [
    { key: 'id', label: 'Mã NV', width: '100px' },
    { key: 'name', label: 'Họ tên', render: (v, r) => `<b>${TXTV.escape(v)}</b>` },
    { key: 'dept', label: 'Bộ phận' },
    { key: 'salary', label: 'Lương', align: 'right', format: 'currency' },
    { key: 'joined', label: 'Ngày vào', format: 'date' }
  ],
  selectable: true, exportable: true, pageSize: 10,
  onRowClick: row => TXTV.toast(row.name)
});
dt.setLoading(true);
TXTV.run('demo_getEmployees').then(rows => dt.setData(rows));
